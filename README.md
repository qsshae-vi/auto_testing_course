# Автоматизированное тестирование - VK Education

Репозиторий с домашними заданиями по курсу автоматизированного тестирования от [VK Education](https://education.vk.company/curriculum/program/discipline/3230/).

## Технологии

- **Java 17** - язык программирования
- **Maven** - сборка проекта и управление зависимостями
- **JUnit 5** - организация и выполнение тестов
- **REST Assured** - автоматизированное тестирование REST API
- **Playwright Java** - автоматизированное UI-тестирование
- **Allure Report** - формирование отчётов о результатах тестирования

## Домашние задания

Каждая домашняя работа выполняется в отдельной ветке репозитория с последующим созданием Pull Request для проверки.

| Ветка | Содержание |
|---|---|
| `homework-4` | Автоматизированное тестирование REST API с использованием REST Assured |
| `homework-5` | UI-автотесты функциональности создания публикаций в Одноклассниках с использованием Playwright и JUnit 5 |
| `homework-6` | Рефакторинг UI-автотестов с применением паттернов проектирования |
| `homework-7` | Оптимизация использованных локаторов |

Подробное описание, структура проекта и инструкции по запуску приведены в `README.md` соответствующих веток.

## UI-тестирование

Для практических заданий по UI-автоматизации используется социальная сеть [Одноклассники](https://ok.ru/).

Тестовые сценарии включают проверку страницы группы, взаимодействие с редактором публикаций, создание и удаление текстовых тем, а также работу с сохранёнными черновиками.

В ходе развития проекта применяются Page Object, Page Component, Loadable Component, Value Object, Chain of Invocations, Data Provider и Facade.

## Запуск тестов

Для выполнения заданий необходимы JDK 17 и Maven.

Перейти в ветку соответствующего домашнего задания и выполнить:

```bash
mvn clean test
```

Для формирования и просмотра отчёта Allure:

```bash
mvn allure:serve
```

Для UI-тестов требуется предварительная настройка авторизации. Подробная инструкция с использованием Playwright Codegen представлена в README соответствующих домашних заданий.
